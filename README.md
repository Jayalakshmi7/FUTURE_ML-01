# AI-Powered Sales Forecasting Dashboard

## 📌 Project Overview  
This project focuses on building an **AI-powered sales forecasting dashboard** using historical retail sales data. The objective is to analyze past sales performance, identify trends and seasonality, and visualize **future sales forecasts** through an interactive **Power BI dashboard**.

The dashboard enables business users to compare **actual vs forecasted sales**, understand category-level performance, and make data-driven decisions based on predictive insights.

---

## 📂 Dataset  
The project uses a **Retail Superstore Sales Dataset** containing order dates, sales values, customer segments, product categories, and regional details.

To support forecasting and visualization, the data was organized into multiple structured files:
- Actual sales data  
- Forecasted sales results with confidence intervals  
- Monthly category-wise sales summaries  

---

## 🔧 Methodology  
1. **Data Cleaning & Preparation**  
   Historical sales data was cleaned and structured for accurate analysis and visualization.

2. **Sales Forecasting**  
   Time-series forecasting techniques were applied to generate future sales predictions and uncertainty ranges.

3. **Dashboard Development (Power BI)**  
   An interactive dashboard was built with:
   - Actual vs Forecasted Sales trend line  
   - Monthly sales analysis  
   - Category-wise performance breakdown  
   - KPI cards for key metrics  
   - Slicers for dynamic filtering  

---

## 🛠️ Tools & Technologies  
- **Power BI** – Interactive dashboard and visual storytelling  
- **Python** – Forecasting output generation  
- **Pandas, Matplotlib** – Data processing and visualization support  

---

## 📊 Key Insights  
- Clear visibility into **future sales trends**  
- Identification of **top-performing and low-performing categories**  
- Better understanding of **seasonality and demand patterns**  

---

## 🚀 Outcome  
The final result is a **business-ready Power BI dashboard** that combines historical analysis with predictive forecasting, enabling stakeholders to plan inventory, marketing, and sales strategies effectively.
